Flex Route Assist v55
================================

これは、これまでの変更をすべて統合したフル版です。
差分パッチではなく、このフォルダ一式だけで最新版へ置き換えられます。

主な統合機能
------------
・初回起動時の架空/サンプル配達データなし
・配達先の登録、編集、削除
・写真から住所読取
・手動住所入力
・地図3秒長押しで配達先登録
・通常タップでは登録画面を開かない
・登録ピンの位置修正、ドラッグ保存
・配達先詳細、建物/部屋、荷物個数、時間指定、メモ
・時間帯別ピン表示
・現在地自動追従
・手動パン/ズーム後は勝手に現在地へ戻さない
・進行方向表示
・地図 2D / 3D
・白背景 / ナイト表示
・建物表示の高速化
・右側のコンパクト地図操作ボタン
・メイン地図は固定、他画面は縦スクロール
・サブ画面のみ右スワイプで戻る
・地図画面では右スワイプ戻る無効
・下部シートは通常ほぼ完全収納
・一般道 / 高速道路 選択
・軽自動車 / 普通乗用車 選択
・高速料金は概算表示
・OSRMによるルート検索
・最大3候補の代替ルート
・選択ルート青、代替ルート灰色
・偽の渋滞色を使用しない
・到着予定時刻、距離、所要時間
・ルートプレビュー
・明確な「ナビ開始」ボタン
・Apple Maps / Google Maps で開く
・アプリ内ナビ
・次の曲がり角、距離、案内表示
・音声ナビ
・音声音量設定
・音声案内 ON / OFF
・音声案内タイミング：早め / 標準 / 直前
・ナビ中の手動「再検索」
・ルート逸脱時の再検索
・ナビ終了時の青いルート線完全削除
・非同期再検索が終了後に線を再描画しない対策
・GPS精度が35mより悪い時だけ警告
・目的地10m以内で「到着しました」
・到着時に荷物情報を表示
・不在 / 配達完了 → 次へ
・完了/不在後、旧ルートを削除
・次の未配達先を自動選択
・次のルートプレビューを自動表示
・本日分終了時の完了表示
・Wake Lock対応端末では画面スリープ抑止
・ナビ状態の保存/復元
・CSVインポート
・バックアップ書き出し/復元
・管理同期URL設定
・配達データ削除

iPhone PWAの制限
---------------
iOSのホーム画面PWAでは、画面ロック中・完全バックグラウンド中に
GPS追跡と音声案内を継続することは保証できません。
完全なバックグラウンドナビにはネイティブiOSアプリ化が必要です。

GitHubへの反映
--------------
このフォルダの中身を、リポジトリ内の
Flex-Route-Assist/
へ丸ごと上書きしてください。

例:
cp -R ~/Downloads/Flex-Route-Assist-FINAL-v54/* \
  ~/Downloads/Flex-Route-Assist-repo/Flex-Route-Assist/

その後:
cd ~/Downloads/Flex-Route-Assist-repo
git add Flex-Route-Assist
git commit -m "Consolidate all Flex Route Assist changes FINAL v54"
git push origin main

・配達実績履歴（日付別、配達完了、不在、処理件数、荷物数、完了時刻）
